# Daynote prototype

一个浏览器扩展弹窗尺寸的交互原型，面向需要随手记录临时事项的开发者。

## 核心设计

- 打开即聚焦编辑区，无需创建文件或输入标题
- 每天一页，左侧自动按日期归档
- 只保留换行与加粗，粘贴内容会转换为纯文本
- 输入后自动保存到 `localStorage`
- 支持浅色/深色主题与完整键盘操作
- 响应式适配 320px 以上宽度

## 预览

直接打开 `index.html`，或在当前目录启动任意静态文件服务：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。
