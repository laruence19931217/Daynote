# Daynote · 随手记

一个打开即写、按天归档、仅保存在本地的轻量浏览器扩展。

## 功能

- 打开扩展后自动聚焦当天编辑区
- 每天一页，自动按日期归档
- 仅保留换行和加粗，粘贴内容自动转换为纯文本
- 输入后自动保存到 `chrome.storage.local`
- 浅色与深色主题
- 完整键盘操作与可见焦点状态
- 不请求网络、网页内容或浏览历史权限

## 本地安装

### Chrome

1. 打开 `chrome://extensions`
2. 开启右上角的“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本项目根目录
5. 建议将 Daynote 固定到浏览器工具栏

### Edge

1. 打开 `edge://extensions`
2. 开启“开发人员模式”
3. 点击“加载解压缩的扩展”
4. 选择本项目根目录

## 项目结构

```text
manifest.json          扩展清单（Manifest V3）
popup.html             扩展弹窗
styles/popup.css       视觉样式
scripts/popup.js       编辑、归档与本地存储逻辑
icons/                 扩展图标
prototype/             已确认的交互原型
```

## 数据说明

笔记和主题设置只存储在当前浏览器配置的扩展本地空间中。扩展没有联网能力，也不会读取当前网页内容。
